# Synthetic review package navigation

The Intake dashboard's `/package` page groups five independent questions: source completeness, excluded records, identity uncertainty, financial totals, and evidenced human review. It shows no combined go-live verdict. Sources, exceptions, and tie-out apply to the demo or the run loaded in that browser. Source readiness (`/readiness`) imports a separate dated package; check its agency, Intake run, and as-of date explicitly because it does not automatically correspond to the loaded run.

The receipt ledger (`/ledger`) opens a separate synthetic export and does not inherit the loaded Intake run. Its bundled example is a committed demo snapshot. The page holds the ledger in browser memory; durable receipt storage is a separate local SQLite finance CLI operation. It provides no hosted persistence.

Bob and Plan Diff links use the existing public demo destinations. They do not transfer the Intake run, agency ID, browser state, or human decision. The public Texas Plan Diff run remains a separately selected source of public carrier evidence; it does not establish client enrollment. New local routes should join their own dashboard navigation only after their page files are delivered. A new local route must not be linked on a public host as if published.

Bob's delivered local `/workflow` page is linked from its own navigation as Evidence workflow. The Intake guide names that local destination without linking an unpublished public route. Workflow context is separately supplied; browser-memory drafts and declared reviewer names are unauthenticated. Accepting evidence neither merges people nor resolves identity.

Local contract tools and browser dashboards have different roles. Contract packages require explicit agency/run identity, pinned snapshot hashes, provenance, and separate synthetic coverage evidence. The review guide does not execute those tools or assert that a joined package has been loaded. Snapshot pins establish consistency, not authenticity. Deterministic identity resolution and plan change flags do not substitute for evidenced human approval.

Browser review labels are not authenticated approval. Real authentication, authorized hosted storage, ERP posting, and permission to process real agency data remain explicit production gates.

Focused checks cover delivered route targets, selected-run Plan navigation, skip links, separate review evidence, and the production gates. The release coordinator owns the complete serial test/build gates and browser review.
